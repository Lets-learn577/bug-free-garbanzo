# Roblox Taxi Boss Fare Calculator

A small web project I made to estimate trip fares in Roblox Taxi Boss. You just pick your starting location, destination, and car type from the dropdowns, and it calculates the payout based on distance.

## What it does
- Lets you choose a pickup point and drop-off location from a dropdown list
- Lets you pick your car type to adjust the fare rate
- Shows the estimated cash payout right away

## Built with
- HTML
- CSS
- JavaScript

## How to run it
1. Download or clone the repo:
   ```bash
   git clone https://github.com
   ```
2. Open the folder and double-click `index.html` to run it in your browser.
